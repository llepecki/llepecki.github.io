# Style drift

Known deviations from the Style reference in `../../CLAUDE.md` (dark chassis). Every entry below is a **deliberate exception** recorded on 2026-10-07; each follows an explicit requirement in `design.md` or the kid-readability clause of `CLAUDE.md`, so a later restyle pass must not "fix" it. None cites a `house/<id>` rule, so the review gate enforces everything else at full strength.

- **48 px stepper hit areas.** `.step-btn` is a 48×48 px transparent button; the house 28 px circle is painted on its inner `<span>`. Design §8 requires at least 48 px hit areas for steppers.
- **Core actions at 18 px on 48 px targets.** `.launch-btn` (Start/Pause/Continue/Try again) and `.engine-btn` (Speed up / Brake / Turn engines off) use 18 px mono text and a 48 px minimum height; every other `.type-btn` has a 44 px minimum height. Design §3 and the readability clause require this for kid-facing actions.
- **Two-line playback glyph buttons.** The ▶ / ▶▶ / ▶▶▶ / ■ buttons carry a visible 11 px rate caption (`1×`, `120×`, `600×`) under the glyph because design §4 requires the rates to be shown, not only spoken.
- **Responsive query `(max-width: 700px), (max-height: 560px)` with page scrolling.** Design §3 replaces the fixed-height mobile chassis with a stacked, scrolling layout so the 360 px drawing, the cabin strip and the large controls stay reachable; the cabin strip itself wraps below about 354 px of stage width.
- **Measured header height.** `.main` uses `calc(100vh - var(--header-h))` with the header measured by a `ResizeObserver` instead of the fixed 80 px budget (design §3).
- **Bottom-left status block instead of a top-center canvas prompt.** The trajectory summary, the state message and the persistent vacuum-model line share one `.status-block` pill so the top of the drawing stays free for the inset and the straight-line comparison.
- **Second canvas.** The cabin is a separate `<canvas id="cabinCanvas">` in a DOM strip below the orbit canvas with DOM readouts beside it, as design §3 specifies; the orbit canvas keeps the house `canvas` recipe.
- **Disclosure buttons.** `.disclosure-btn` is a `.type-btn` restyled with Outfit 15 px and a `+`/`−` indicator because the panel holds four inline help sections (More physics, Why, Terms, Sources) rather than a single collapsed help block.
- **Engine domes.** Speed up and Brake are the hold-to-fire `.engine-btn` domes ported from `../../hohmann/index.html` (80 px, radius 16 px, `touch-action: none`, `user-select: none`), which the Captain chose on 2026-10-07 over the house segmented buttons; their 18 px captions carry the labels.
- **Cabin and station outline.** Rounded outline with four identical `#8fc1ff` walls at 2 px in the cabin canvas and the close-view marker (the Captain's choice on 2026-10-07; the white floor edge was dropped the same day); this is an entity color, not a chrome accent. The trail uses the Gravity Assist trajectory yellow `rgb(255, 224, 102)` for the same reason; the predicted path is a solid `--text-dim` line.
- **Hero readouts in the cabin strip.** Gravity and wall push use 20 px mono values in entity colors (`--gravity`, `--contact`) because they are the first prominent comparison in the lesson (design §7).
